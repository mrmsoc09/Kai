# OWASP-ZAP Output Patterns

## Alert Structure
- Alert ID
- Alert name (vulnerability type)
- Risk level (High/Medium/Low)
- Confidence (High/Medium/Low)
- URI affected
- Request/response examples

## High Severity Examples
- SQL injection found
- XSS vulnerability
- Remote code execution indicators

## Medium Severity
- Missing security headers
- Insecure cookie settings
## Informational
- Page titles, server identification
