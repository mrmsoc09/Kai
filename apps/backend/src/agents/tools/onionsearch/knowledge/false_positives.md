# Onionsearch False Positives

## Common Issues
1. **Index Lag**: Results from months or years-old breaches already public
2. **Duplicate Listings**: Same data dump on multiple .onion mirrors
3. **Partial Matches**: Org name substring in unrelated context
4. **Spam Pages**: Fake announcements without actual data
5. **Archived Content**: Legitimate pages mirrored on .onion

Cross-verify with breach timeline and actual .onion crawl before escalating.
