# Wafw00f Use Cases

## Active Scan Safety Gate
Use WAF status to prevent early blocking and preserve scan continuity.

## Payload Strategy Selection
Apply lighter payload classes and spacing when WAF is detected.

## Multi-Host Profiling
Large targets may have mixed WAF coverage; maintain host-level adaptation settings.

## Analyst Communication
Include explicit WAF state in handoff summaries so operators understand why scan rates changed.
