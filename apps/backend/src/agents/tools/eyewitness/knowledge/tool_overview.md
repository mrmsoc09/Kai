# EyeWitness

EyeWitness captures screenshots and compiles HTML reporting for discovered web services. It is complementary to GoWitness and can surface content differences due to rendering or execution behavior.

## Primary Purpose
Create browseable visual reports that accelerate analyst triage.

## Output
Generates report artifacts in an output directory with page previews and metadata.

## Pipeline Role
Runs in visual recon stage and feeds high-interest targets into enumeration and vuln scanning.

## Distinct Benefit
Its report-centric workflow is useful for operator handoff and asynchronous review.
