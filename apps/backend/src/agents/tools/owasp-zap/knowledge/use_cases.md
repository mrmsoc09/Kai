# OWASP-ZAP Use Cases

## Scenario 1: Initial Active Scan
Fresh target. ZAP quick-scan provides broad vulnerability overview.

## Scenario 2: WAF Bypass Testing
Target has WAF. ZAP includes evasion techniques. Tests if WAF is effective.

## Scenario 3: Session Management Testing
Login-required endpoints. ZAP tests for authentication bypass, session fixation.

## Scenario 4: Complement to Nuclei
Nuclei: Template-based, known CVEs. ZAP: Active testing, unknown patterns.

## Scenario 5: Baseline Comparison
Run ZAP before and after remediation. Measure improvement.
