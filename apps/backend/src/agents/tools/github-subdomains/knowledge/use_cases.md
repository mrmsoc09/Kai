# Github-Subdomains Use Cases

## Internal Surface Discovery
Use code-search-derived hosts to reveal internal service planes and forgotten staging endpoints.

## Credential Exposure Triage
Pair with secret-scanning tools when repositories leak hostnames and tokens in adjacent files.

## Program Expansion
For broad programs, this tool can uncover acquisition or business-unit naming patterns not visible in CT logs.

## Early Prioritization
Promote hosts with admin/auth/internal labels into rapid validation and screenshot workflows.
