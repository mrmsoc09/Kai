# waybackurls — Output Patterns

## HIGH SIGNAL URL Patterns
Same as gau — look for interesting paths and parameters.

## Additional Value: Date Filtering
Date filtering reveals when endpoints were active, suggesting which ones may still be live on legacy backend systems.

Old URLs (before 2020) are especially valuable:
- May expose deprecated API versions
- Often have weaker authentication
- Legacy CSRF, IDOR, and injection bugs
