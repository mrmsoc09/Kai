# SpiderFoot Overview

SpiderFoot is an OSINT automation platform that can query 200+ data sources and produce structured intelligence findings. In KAISON it is used under controlled module sets configured by orchestration policy.

## Core Role
- Perform broad passive intelligence collection
- Surface credential leaks, breach indicators, and exposure metadata
- Provide escalation-grade evidence for analyst review

## Safety Principle
SpiderFoot findings are intelligence artifacts only; discovered credentials must never be used operationally.
