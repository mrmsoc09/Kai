# SearchSploit Use Cases

## Scenario 1: Version-Based Matching
Nikto identifies Apache 2.2.15. SearchSploit returns 40+ known exploits. Feed CVE IDs to Nuclei.

## Scenario 2: CVE Baseline
After CVE announcement, SearchSploit quickly shows if vulnerable version is in scope.

## Scenario 3: PoC Reference
Exploit code published in ExploitDB. SearchSploit finding lets analyst access PoC for understanding.

## Scenario 4: Supply Chain Risk
Dependency audit. Tool X version Y has 5 known exploits. Upgrade recommendation.

## Scenario 5: Continuous Monitoring
Periodic version detection + SearchSploit identifies when new exploits published.
