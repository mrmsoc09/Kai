# Ahmia-Client Use Cases

## Scenario 1: Quick Triage
Fast dark web index check for org without Tor setup.

## Scenario 2: Complementary Coverage
Run alongside Torbot and Onionsearch. Query different indices. Maximize coverage.

## Scenario 3: Clearnet-Only Environment
When Tor unavailable, Ahmia provides dark web search via standard HTTP.

## Scenario 4: Breach Verification
After breach news, quickly confirm data in dark web indices.

## Scenario 5: Competitor Intelligence
Identify if competitor orgs mentioned in dark web context alongside target.
