# Custom Wordlist Generator

A context-aware wordlist generation tool for fuzzing and brute-forcing, featuring web scraping, AI-driven keyword expansion (Kimi k2.5 style logic), and modular processing pipelines.

## Features

- **Web Scraping**: Intelligent spider with context-aware keyword extraction
- **AI-Driven Expansion**: Semantic keyword expansion using Kimi k2.5 architectural patterns
- **Permutation Engine**: High-performance rule-based mutation (leet speak, years, special chars)
- **Modular Architecture**: Plugin-based filters and mutators
- **Async Processing**: High-performance async/await throughout
