Enable JS crawl to reveal routes hidden from static link extraction.

Automatically isolate GraphQL endpoints and route them to GraphQL-focused tools.

Use katana output to enrich URL corpora before gf pattern categorization.

## Scenario 4: WAF-Safe Crawl
Throttle crawl rates and reduce request spikes on protected targets.

## Scenario 5: JS Review Queue
Prioritize discovered JS files for secret and endpoint reference analysis.
