# Onionsearch Use Cases

## Scenario 1: Fast Dark Web Triage
Need quick answer on dark web mentions. Onionsearch query returns results in seconds vs. Torbot crawl in minutes.

## Scenario 2: Credential Marketplace Monitoring
Periodic Onionsearch for org name finds new listings faster than crawling.

## Scenario 3: Combining with Torbot
Onionsearch identifies promising .onion sources. Torbot crawls them for full content.

## Scenario 4: Query Variation Testing
Run multiple query formats to maximize recall.

## Scenario 5: Baseline Establishment
Initial onionsearch establishes if org has ANY dark web presence before deeper investigation.
