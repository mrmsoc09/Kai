# HTTPX Probe Overview
HTTPX is a high-performance HTTP toolkit used for probing subdomains, discovering live hosts, and fingerprinting technologies. It is essential for shifting from passive discovery to active validation.

## Key Features
- **Tech-Detect**: Identifies web frameworks, CMS, and server software.
- **CDN Identification**: Flags if a host is behind a CDN (Cloudflare, Akamai, etc.).
- **Response Analysis**: Filters and parses status codes, titles, and content lengths.
