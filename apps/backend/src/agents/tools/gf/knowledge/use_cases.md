# GF Use Cases

## Scenario 1: SQLi Queue Construction
Feed matched URLs into sqlmap input files.

## Scenario 2: XSS Campaign Seeding
Forward reflected/search-style URLs to dalfox for payload testing.

## Scenario 3: SSRF Candidate Isolation
Extract URL/path include candidates for ssrfmap and manual verification.

## Scenario 4: Manual Review Enforcement
Route RCE and sensitive IDOR categories to human review queue.

## Scenario 5: Pattern Tuning
Iteratively refine patterns based on false-positive observations per program.
