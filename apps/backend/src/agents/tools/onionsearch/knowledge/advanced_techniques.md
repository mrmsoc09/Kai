# Onionsearch Advanced Techniques

## Query Types
- Organization name: "CompanyName"
- Breach data: "CompanyName leaked"
- Credential terms: "CompanyName password"
- Database exports: "database dump CompanyName"

## Index Coverage
Searches multiple .onion indices. Different coverage from Ahmia (clearnet index) and Torbot (crawl-based).

## Combining Tools
Onionsearch finds indexed references fast. Torbot crawls for deeper content. Ahmia provides clearnet index coverage. Use all three for complete dark web intelligence.

## Output Processing
JSON format with URL results and snippets. Parse for target organization mentions and links to .onion resources.
