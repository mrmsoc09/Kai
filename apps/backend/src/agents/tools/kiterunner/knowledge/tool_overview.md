# Kiterunner Overview
Kiterunner is a high-performance tool for modern API discovery. Unlike traditional wordlist-based tools, it uses structured wordlists (kite files) to find API endpoints.

## Key Features
- **Kite Files**: Pre-built structured wordlists for common API frameworks.
- **Fast Scanning**: Optimized for high-throughput scanning of thousands of endpoints.
- **Detailed Output**: Includes method, status code, and content length for each endpoint.
