# Faraday-Community Advanced Techniques

## Deduplication Method
Match on (type, value, target). Identical findings from different tools = single entry.

## Confidence Boosting
Multi-tool confirmation increases confidence. Single tool = 0.7-0.9. Two tools = +0.1 each.

## Master Findings
Single source of truth. Deduplicated, confidence-boosted, tool-confirmed.

## Why Deduplication Matters
Torbot + Onionsearch + Ahmia might find same dark web resource. Report once with multi-tool confirmation.

## Tool Intersection Validation
Finding confirmed by 3+ tools = very high confidence for reporting.
