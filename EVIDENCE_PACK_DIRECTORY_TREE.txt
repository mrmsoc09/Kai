FINDING LIFECYCLE: DATA FLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. DISCOVERY (Tool Output)
   ├─ Tool executes in workflow
   └─ Output stored: output/raw/wf-{uuid}/{tool}_*.json

2. VALIDATION (Scope Check)
   ├─ Scope validation gate applied
   ├─ Decision logged: output/logs/scope_decisions.jsonl
   └─ Status: IN_SCOPE|OUT_OF_SCOPE|REQUIRES_APPROVAL

3. RECORDING (Evidence Capture)
   ├─ Playwright records exploitation video
   ├─ Video saved: vault/evidence/recordings/{task_id}_recording.webm
   ├─ Metadata: vault/evidence/recordings/{task_id}_recording.json
   └─ Status: RECORDED (logged to finding_status.jsonl)

4. SCRIPT GENERATION (Reproducibility)
   ├─ Extract HTTP requests from recording
   ├─ Generate curl command: vault/evidence/scripts/{task_id}_repro.sh
   ├─ Generate Python script: vault/evidence/scripts/{task_id}_repro.py
   ├─ Generate exploit.py: vault/evidence/scripts/{task_id}_exploit.py
   └─ Status: SCRIPTED (logged to finding_status.jsonl)

5. BUNDLING (Package Evidence)
   ├─ Collect all evidence files
   ├─ Create ZIP: vault/evidence/hil_bundles/{task_id}_{bundle_id}_evidence.zip
   ├─ Generate metadata: vault/evidence/hil_bundles/{task_id}_{bundle_id}_evidence.json
   ├─ Create README with instructions
   └─ Status: BUNDLED (logged to finding_status.jsonl)

6. MANUAL APPROVAL (HiL Review)
   ├─ Security expert reviews bundle
   ├─ Expert validates with one of: repro.sh, repro.py, exploit.py
   ├─ Expert signs with PGP: gpg --detach-sign --armor {task_id}.txt
   ├─ Expert submits: k1 approve {task_id} --pgp-sign <signature>
   ├─ Signature verified: vault/governance/pgp_keys/{approver_id}.pub
   ├─ Status logged: vault/governance/approval_audit.jsonl
   └─ Status: APPROVED (logged to finding_status.jsonl)

7. PLATFORM SUBMISSION (Final Delivery)
   ├─ Check approval status: can_submit_to_platform({task_id})
   ├─ BLOCKS if: no PGP signature OR signature expired OR status != APPROVED
   ├─ SUBMITS to: HackerOne API / Bugcrowd API / Intigriti API
   ├─ Queued in: artifacts/submissions/outbox/
   └─ Status: SUBMITTED (logged to finding_status.jsonl)
