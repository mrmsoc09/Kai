# Hakrawler Overview

Hakrawler is a fast URL extraction crawler designed to gather links, script references, and form-action candidates from live web responses. It complements deeper crawlers by producing quick, low-latency path discovery results.

## Core Role
- Rapidly collect in-scope URLs
- Surface API-like paths and form actions
- Supply additional seeds to content discovery and categorization agents

## Complement Value
Hakrawler and Katana use different crawling behavior. Running both improves endpoint recall and reduces blind spots.
