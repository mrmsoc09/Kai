# Subfinder Overview
Subfinder is a subdomain discovery tool that returns valid subdomains for websites by using passive online sources. It has a modular architecture and is optimized for speed. Subfinder is built for only one thing - passive subdomain enumeration, and it does that very well.

## Passive Sources
It uses various passive APIs (BinaryEdge, C99, Censys, CertSpotter, Chaos, Chinaz, DNSTrails, Fofa, Google, Intelx, PassiveTotal, Quake, Robtex, SecurityTrails, Shodan, Spyse, ThreatBook, Virustotal, WhoisXML API, ZoomEye) to gather data without sending a single packet to the target infrastructure.
