# Mindmap Integration System

An autonomous Python tool for generating and managing architectural mindmaps from codebases, security scans, and AI-driven brainstorming sessions.

## Features

- **Automated Codebase Mapping**: Extract architecture from Python, JavaScript, Java, Go, and Rust codebases using AST analysis
- **Security Visualization**: Parse SARIF and JSON scan results to create attack surface visualizations
- **AI-Driven Brainstorming**: Intelligent expansion of ideas using architectural and security pattern recognition (Kimi k2.5 logic)
- **Multi-Format Support**: Export to Mermaid.js, PlantUML, or Markdown with embedded diagrams
- **Documentation Integration**: Seamless integration with CI/CD and documentation workflows
