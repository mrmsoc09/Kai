# Social-Analyzer Overview

Social-Analyzer provides deeper metadata-centric social profile analysis than simple username existence checks. It captures profile details useful for intelligence enrichment and analyst triage.

## Core Role
- Enrich social profile records
- Capture platform metadata, bios, links, and activity hints
- Complement Sherlock with depth-first profile context

## Pipeline Position
Used after profile discovery to convert surface-level hits into actionable intelligence artifacts.
