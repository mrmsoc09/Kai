# Torbot False Positives

## Common Misidentifications
1. **Substring Matches**: Organization name appears as substring in unrelated context (e.g., "Admin" matching "Administrator")
2. **Stale Data**: Breaches referenced are already public knowledge from years prior
3. **Spam Pages**: Auto-generated .onion directory pages with keyword stuffing
4. **Archived Content**: Legitimate org content archived on .onion mirrors, not breach evidence
5. **Collisions**: Common words matching unrelated sites

Always cross-reference findings with:
- Known breach databases (HaveIBeenPwned)
- Recent news about the organization
- Credential marketplace activity timelines
