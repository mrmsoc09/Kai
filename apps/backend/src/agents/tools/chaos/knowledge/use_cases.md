# Chaos Use Cases

## Instant Recon Seed
When a target is in the dataset, chaos can produce immediate target seeds for downstream workflow.

## Community Intelligence Layer
Use chaos as a high-confidence complement to pure-source passive tools.

## Program Triage
Fast checks across multiple bug bounty programs can identify where deeper recon effort should be allocated.

## Handoff Efficiency
Include chaos confidence context in handoff reports so downstream agents can prioritize likely-real assets first.
