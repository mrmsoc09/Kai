# GoWitness

GoWitness captures screenshots and metadata for web targets at scale. It provides visual reconnaissance that complements purely textual fingerprinting and helps identify high-value interfaces quickly.

## Primary Purpose
Generate screenshot evidence and page metadata for live web endpoints.

## Output Characteristics
Screenshots are written to disk; metadata may be available via stdout or database artifacts.

## Pipeline Role
Runs after host liveness checks and before deeper content discovery and vulnerability scanning.

## Analyst Value
Visual context accelerates prioritization of login portals, admin panels, and exposed debug interfaces.
