# Kaison K1 Platform

**Enterprise Security & Vulnerability Research Platform**

## 🚀 Quick Start

```bash
./bootstrap.sh
./k1 start
```

Please refer to [README_ENTERPRISE.md](./README_ENTERPRISE.md) for the complete user guide.

### Key Features
*   **Unified Startup:** Single script handles configuration and boot.
*   **Whonix Integration:** Route tool traffic through Tor/Whonix.
*   **Kaison Composer:** Advanced AI engine (powered by GPT-4.1).
*   **Key Management:** Bulk import 75+ API keys via CSV/PDF.
*   **Enterprise UI:** High-contrast dark mode for SOC environments.
