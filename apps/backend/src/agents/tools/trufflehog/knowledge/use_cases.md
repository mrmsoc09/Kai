# Trufflehog Use Cases

## Scenario 1: Public Repository Audit
GitHub/GitLab public repo contains committed secrets in history. Critical finding.

## Scenario 2: Post-Breach Assessment
After data breach, scan source code history for leaked credentials in commit logs.

## Scenario 3: Third-Party Supply Chain Risk
Vendor code scan discovers hardcoded API keys. Supply chain security validation.

## Scenario 4: Compliance Audit
PCI-DSS/SOC2 audit requires verification no credentials in source history.

## Scenario 5: Continuous Monitoring
Periodic scanning of repo history monitors for accidental credential commits.
