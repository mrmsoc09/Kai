# Ahmia-Client Output Patterns

## High Value Signals
- Indexed .onion pages with target org name
- Data breach mentions with download links
- Credential marketplace listings
- Ransom pages targeting organization
- Leaked config or source code references

## Medium Signal
- Forum discussions mentioning target
- Historical breach references
- Tangential data dump mentions

## Noise Patterns
- Unrelated onion services
- Cryptocurrency mixers
- Index navigation
- Irrelevant archived content
