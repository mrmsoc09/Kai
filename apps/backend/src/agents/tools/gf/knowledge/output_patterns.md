# GF Output Patterns

## Category Outputs
- SQLi candidates
- XSS candidates
- SSRF candidates
- Redirect candidates
- IDOR candidates
- RCE manual-review candidates

## Routing Model
- SQLi -> sqlmap
- XSS -> dalfox
- SSRF -> ssrfmap
- IDOR/RCE -> manual or analyst queue

## Value
Pre-qualified routing reduces indiscriminate scanning and improves downstream signal density.
