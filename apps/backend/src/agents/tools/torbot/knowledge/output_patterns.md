# Torbot Output Patterns

## High Value Signals
- Org name in page title or meta description
- Database dump announcements with org identifier
- Credential marketplace listings for org domain
- Ransom demand pages with org name
- Leaked configuration files or source code mentions

## Medium Signal
- Forum discussions mentioning org
- Archived copies of org pages on .onion
- Tangential references to org data

## Noise Patterns
- Unrelated .onion hosting services
- Cryptocurrency mixers and gambling sites
- Navigation pages without content
- Archived web mirrors of unrelated content
