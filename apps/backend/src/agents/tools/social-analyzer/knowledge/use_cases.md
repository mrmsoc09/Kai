# Social-Analyzer Use Cases

## Scenario 1: Deep Profile Enrichment
Expand profile hits from Sherlock with structured metadata.

## Scenario 2: Evidence Preparation
Produce analyst-ready summaries of platform presence and profile context.

## Scenario 3: Link Pivoting
Follow profile outbound links to identify additional intelligence surfaces.

## Scenario 4: Confidence Scoring
Rank profiles by metadata completeness and relevance indicators.

## Scenario 5: Reporting
Attach profile metadata snapshots to OSINT evidence records for review.
