# BruteFuzz

High-performance, modular brute-forcing and fuzzing suite with AI-driven feedback loops.

## Features

- **Modular Protocol Handlers**: HTTP/HTTPS, SSH, extensible base class
- **Advanced Wordlist Generation**: File-based, combinatorial, and mutation strategies
- **WAF Evasion**: Multiple encoding techniques, randomization, and comment insertion
- **Adaptive Rate Limiting**: Intelligent backoff with jitter to avoid detection
- **AI-Driven Feedback**: Kimi k2.5 logic for context-aware payload mutation
- **Real-time Statistics**: Live monitoring of success rates and performance metrics
