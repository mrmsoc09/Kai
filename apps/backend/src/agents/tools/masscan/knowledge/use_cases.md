# Masscan Use Cases

## Large Surface Triage
Use masscan to quickly establish where deeper scanning effort should be spent.

## Continuous Exposure Monitoring
Periodic scans can flag newly opened ports caused by deployment drift.

## Pre-Enrichment Queue Builder
Generate a concise target list for nmap and vuln-oriented tools.

## Incident Support
During active response, masscan helps validate if sensitive services became externally reachable.
