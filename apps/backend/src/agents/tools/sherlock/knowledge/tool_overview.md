# Sherlock Overview

Sherlock performs username enumeration across hundreds of social platforms. It is useful for correlating employee handles, researcher aliases, and open-source identity signals tied to target organizations.

## Core Role
- Discover profile URLs for candidate usernames
- Identify high-value platforms (GitHub, LinkedIn, HackerOne)
- Trigger repository intelligence when GitHub profiles are found

## Intelligence Value
Platform presence patterns can improve organizational mapping and influence OSINT task prioritization.
