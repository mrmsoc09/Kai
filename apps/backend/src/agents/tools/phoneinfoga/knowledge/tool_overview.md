# Phoneinfoga Overview

Phoneinfoga performs phone-number intelligence lookups including carrier, region, and linked account correlation signals. It supports OSINT enrichment when phone artifacts appear in authorized scope data.

## Core Role
- Enrich discovered phone numbers
- Identify linked social account clues
- Generate username leads for follow-on social enumeration

## Scope Reminder
Phone intelligence must be handled under strict legal/policy boundaries and only for authorized targets.
