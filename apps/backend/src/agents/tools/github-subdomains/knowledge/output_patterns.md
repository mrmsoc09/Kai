# Github-Subdomains Output Patterns

## High-Value Labels
- `internal.target.com`
- `dev-api.target.com`
- `staging-admin.target.com`
- `service.target.com`
- `micro-auth.target.com`

These labels often correspond to non-public environments and service-to-service interfaces.

## Signal Characteristics
Code-derived subdomains can be stale, but they often reveal naming conventions and architecture boundaries useful for expanding recon.

## Handoff
Forward both discovered hostname list and associated repo references to downstream agents.
