# Nmap Use Cases

## Post-Masscan Enrichment
Run nmap after high-speed discovery to get reliable service/version intelligence.

## CVE Prioritization
Use version-rich findings to rank targets by likely exploitability.

## Misconfiguration Hunting
Identify unexpectedly exposed data services in web-centric environments.

## Evidence-Grade Reporting
Attach service/version lines and XML artifacts to handoff outputs for reproducible analyst verification.
