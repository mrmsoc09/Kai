# EyeWitness False Positives

## Report Parsing Drift
Minor version changes can alter report HTML layout and break brittle parsers.

## CDN/Edge Uniformity
Many hosts may render the same edge page, appearing distinct while representing one shared control layer.

## Timing Effects
Screenshots can capture transitional states during deploy windows.

## Mitigation
Use metadata correlation and repeat captures before concluding unique exploitable surfaces exist.
