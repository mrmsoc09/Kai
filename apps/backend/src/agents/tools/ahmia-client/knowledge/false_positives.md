# Ahmia-Client False Positives

## Common Issues
1. **Stale Index Data**: Ahmia may index old breach data months or years after
2. **Duplicate Listings**: Same data appears under multiple .onion mirrors
3. **Partial Matches**: Org substring in unrelated context
4. **Spam Entries**: Fake announcements without actual data
5. **Tor2Web Mirrors**: Archived website mirrors using clearnet gateways

Cross-verify with actual .onion crawl before escalating.
