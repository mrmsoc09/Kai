# Phoneinfoga Advanced Techniques

## Baseline Command
`phoneinfoga scan -n +15551234567`

## Input Sources
Phone numbers can originate from public docs, OSINT artifacts, bug bounty assets, or disclosure pages in scope.

## Correlation Path
Extract linked usernames/accounts and hand them to Sherlock or deeper profile analysis workflows.

## Data Handling
Treat all phone intelligence as sensitive; record provenance and avoid over-asserting identity conclusions.
