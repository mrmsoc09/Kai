# Caido Use Cases

## Scenario 1: API Security Audit
REST/GraphQL API assessment. Caido modern engine finds API-specific issues.

## Scenario 2: WebSocket Testing
Real-time applications using WebSocket. Caido analyzes WebSocket traffic patterns.

## Scenario 3: Rate Limiting Bypass
Caido identifies patterns to bypass rate limiting. Different from traditional scanners.

## Scenario 4: Graceful Fallback
If Caido not available in environment, agent skips without breaking pipeline.

## Scenario 5: Complement to ZAP
ZAP: Traditional web apps. Caido: Modern APIs. Use both for complete coverage.
