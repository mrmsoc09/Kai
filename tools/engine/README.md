# Forge Engine - Custom Script and Tool Creation Engine

An autonomous Python framework that designs and builds security tools from high-level descriptions using AI-driven architecture (Kimi k2.5 logic).

## Features

1. **Library of Tool Primitives**: Modular components for scanners, exploits, and parsers
2. **Automated Project Scaffolding**: Generates complete project structure with best practices
3. **Binary Compilation**: Packages tools as standalone executables using PyInstaller
4. **AI-Driven Architecture**: Intelligent component selection and workflow design
