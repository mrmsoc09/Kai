# Onionsearch Output Patterns

## High Value Signals
- Data dump announcements with org identifier
- Credential marketplace listings
- Ransom notes mentioning org
- Leaked file database entries

## Medium Signal
- Forum references to org breaches
- Historical breach mentions
- Peripheral data dump references

## Noise Patterns
- Unrelated onion directory services
- Generic marketplace listings
- Index navigation pages
- Archived content unrelated to target
