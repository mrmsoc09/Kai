# Caido Advanced Techniques

## Modern Engine
Designed for modern APIs (REST, GraphQL, WebSocket). Better than older proxies.

## API-First Design
Focus on API security vs. traditional web app security.

## Interactive vs Automated
Can be used interactively or fully automated. We use automated mode.

## Request/Response Analysis
Detailed inspection of HTTP/WebSocket traffic patterns.

## Graceful Degradation
If not installed, agent skips silently. No error. Continues with other scanners.
