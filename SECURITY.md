# Security Policy

## Supported Scope

This repository is an authorized defensive security research platform.  
Do not use it for unauthorized scanning, exploitation, or credential attacks.

## Reporting a Vulnerability

Please report vulnerabilities privately. Do not open a public issue with exploit details.

Preferred channels:

1. GitHub Security Advisory ("Report a vulnerability" in the repository Security tab)
2. If advisory flow is unavailable, contact maintainers privately and include:
   - affected component and file path
   - reproduction steps
   - impact assessment
   - suggested mitigation (if known)

## What to Expect

- Initial acknowledgement target: 3 business days.
- Triage target: 7 business days.
- A remediation plan or status update will be provided after triage.

## Disclosure Guidance

- Coordinate disclosure with maintainers.
- Avoid publishing secrets, tokens, or customer data.
- Provide minimal proof-of-concept needed to verify impact.

## Operational Safety Expectations

- Respect scope validation and approval gates.
- Preserve auditability and intention tracking in all security-sensitive changes.
