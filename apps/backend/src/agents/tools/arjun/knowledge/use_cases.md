# Arjun Use Cases

## Scenario 1: API Hidden Param Discovery
Target API endpoints discovered in Phase 3 for hidden key enumeration.

## Scenario 2: Auth Flow Analysis
Run against login/reset/profile endpoints to uncover backend-only control parameters.

## Scenario 3: SQLi Prep
Forward ID-like and object-reference params to sqlmap.

## Scenario 4: XSS Prep
Forward callback/search/display parameters to dalfox.

## Scenario 5: SSRF Prep
Forward URL/path/include parameters to ssrfmap and manual validation.
