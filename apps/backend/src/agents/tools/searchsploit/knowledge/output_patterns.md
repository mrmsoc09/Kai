# SearchSploit Output Patterns

## Exploit Information
- EDB-ID (exploit database ID)
- Title (description of exploit)
- Type (RCE, PrivEsc, XSS, etc.)
- Platform (Linux, Windows, Web, etc.)

## Confidence
Usually high. Known CVE and confirmed exploit exists in database.

## CVE Cross-Reference
Use ExploitDB ID to find corresponding CVE number.
