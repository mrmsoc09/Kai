## 🔧 Configuration Required

### Optional Services
These services are optional and will gracefully degrade if not configured:

1. **Ollama** - Install from https://ollama.ai for AI features
2. **Neo4j** - Set NEO4J_PASSWORD env var for graph features
3. **Email Provider** - Configure in Notifications settings
4. **Slack/Webhooks** - Configure in Notifications settings

### Required Services
These are required and auto-initialized:

1. **KaiOrchestrator** - Core engine (auto-starts)
2. **Log Watchdog** - Monitoring (auto-starts)
3. **Intelligence Engine** - RSS feeds (auto-starts)
