# Katana Overview

Katana is a modern web crawler designed for security reconnaissance. It supports JavaScript-aware crawling and structured extraction, making it suitable for finding hidden endpoints and GraphQL surfaces.

## Core Role
- Crawl dynamic applications
- Extract rich endpoint metadata
- Surface JavaScript files and GraphQL routes for specialized follow-on testing

## Key Flags
`-jc` enables JavaScript crawling and `-kf all` collects broad field coverage for stronger downstream analysis.
