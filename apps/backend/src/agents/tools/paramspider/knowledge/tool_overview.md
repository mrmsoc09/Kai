# Paramspider Overview

Paramspider collects parameterized URLs from historical web archives (including Wayback-derived sources). It is passive and safe, making it ideal for early parameter surface mapping without direct target interaction.

## Core Role
- Harvest URL parameters from historical data
- Build candidate parameter corpus
- Feed focused injection testing workflows

## Strength
High coverage for legacy endpoints and forgotten parameter names that may still be processed server-side.
