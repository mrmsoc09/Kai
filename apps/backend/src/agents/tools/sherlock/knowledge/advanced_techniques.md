# Sherlock Advanced Techniques

## Baseline Command
`sherlock username --output sherlock.txt --print-found`

## Input Strategy
Generate candidate usernames from employee OSINT, leaked metadata, and naming conventions.

## Priority Platforms
GitHub and HackerOne profiles often reveal security tooling, research history, and repo links. LinkedIn supports team/role intelligence.

## Handoff Rule
Any discovered GitHub profiles should trigger repository scanning and domain extraction workflows.
