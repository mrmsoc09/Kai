# ReconFTW Overview

ReconFTW is a meta-recon framework that orchestrates multiple discovery steps. In KAISON it is used in recon-only mode as a supplemental signal source, not as a replacement for dedicated per-tool agents.

## Core Role
- Produce quick broad reconnaissance summaries
- Surface candidate subdomains and recap metrics
- Provide additive intelligence for deduplicated target sets

## Positioning
ReconFTW output is supplementary and should be correlated with primary specialized agents.
