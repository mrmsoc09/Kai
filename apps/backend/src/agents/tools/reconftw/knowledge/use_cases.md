# ReconFTW Use Cases

## Scenario 1: Rapid Baseline Snapshot
Generate quick reconnaissance context at campaign start.

## Scenario 2: Supplemental Delta Discovery
Identify candidate subdomains that dedicated runs may have missed.

## Scenario 3: Cross-Validation
Use reconftw summaries to corroborate or challenge primary tool findings.

## Scenario 4: Lightweight Monitoring
Periodic recon-only runs can surface broad drift signals over time.

## Scenario 5: Handoff Enrichment
Attach recon summary stats to downstream routing decisions for analyst context.
